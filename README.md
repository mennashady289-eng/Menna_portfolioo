# Menna Allah Shady — Portfolio

## Structure (flat — no folders, no external images needed)
```
menna-portfolio/
├── index.html
├── styles.css
└── script.js
```

Your photos are already embedded directly inside `index.html` (as base64), so there
are **no separate image files to upload** — just these 3 files.

## How to upload to GitHub
1. Create a new repository (Public).
2. **Add file → Upload files**.
3. Drag all 3 files together: `index.html`, `styles.css`, `script.js`.
4. Commit changes.
5. Settings → Pages → Source: `Deploy from a branch`, Branch: `main`, folder: `/ (root)` → Save.
6. Open `https://<your-username>.github.io/<repo-name>/` after ~1 minute.
